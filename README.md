# Мой трекер

Приложение на HTML/CSS/JavaScript без внешних зависимостей. Нужен Node.js LTS.

## Локальный запуск
Из корня проекта: `npm run dev`. Открыть http://localhost:3000. Остановить Ctrl+C.
Не открывать HTML через file://.

## Проверки
`npm test` — тесты логики. Затем сценарии из PLAN.md в браузере.

## Данные и публикация
Данные только в localStorage текущего origin; нет входа и синхронизации. Папка docs предназначена для GitHub Pages (main /docs). Сервер scripts на хостинг не публикуется.
